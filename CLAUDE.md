# leanc agent directives
audience: AI only. optimize for machine efficiency. no human-oriented prose anywhere.

## code
- MUST NOT: `#` comments, docstrings (module/class/function), `# noqa`, `# type: ignore`, pragmas. scope: leanc/ tests/ scripts/.
- MUST: express intent via names, UPPER_CASE constants, small named functions, Enum/Literal/frozen dataclass.
- MUST: every .py file in leanc/ tests/ scripts/ <= 600 lines (split by responsibility; shared test helpers -> tests/<area>_support.py).
- MUST NOT: write human docs/notes; machine-critical constraints -> this file, one line each.
- exception: README.md (en) README.zh-Hans.md README.zh-Hant.md = developer usage guide; keep the three in sync with CLI behavior and with each other.

## verification invariants
- success only if every required gate ran and passed. timeout/unparsable/skipped/tool error != success.
- VERIFIED_BOUNDED never -> PROVED. PROVED only from required wp gate PASS on approved ACSL contract, and only if every semantic compile.flags entry is applied by WP (backends/wp/compile_flags: applied = last char-signedness entry == machdep char signedness, last -std= in C11 spellings; diagnostics/-g = no effect; everything else incl. -D/-U/-I = not applied -> wp INCONCLUSIVE, Frama-C-model verdict kept in details.frama_c_model_verdict, not proof-repairable).
- protected files (spec, harness, tests driver, headers, lean spec/vectors) never written by generation/repair.
- sanitizer cbmc wp lean run only after integrity PASS; integrity absent or non-PASS -> SKIPPED (unchecked code never executed/model-checked/proved). repair_loop: integrity non-PASS -> PASS is progress only if every gate that ran before keeps its PASS and gains no failure.
- cbmc: body-less callee outside bodiless.MODELLED_BODILESS_* -> gate never PASS; violation whose trace assigns its return value (return_value_<f>) -> diagnostic, never counterexample; other violations stay counterexamples.
- integrity macro check: gcc dumps mirror each verifier's own preprocessing (backends/verifier_macros.py); CBMC mirror pinned to cbmc --preprocess, Frama-C mirror (-undef -nostdinc -imacros of -print-machdep-builtin-macros) pinned to a frama-c -cpp-command capture; change together with cbmc/compile_flags.py and wp/argv.py.
- integrity frame check reads clang -fstack-usage output; no .su file or an unparsed row -> ERROR, never PASS.
- known gaps (not detected): divergent macro names built by ##; header-defined macros that differ between tools (M_PI); frame size measured per function at -O0 (protected-header __OPTIMIZE__ branches measured in -O0 form); protected header marking itself system (#pragma GCC system_header, linemarker flag 3) or carrying a diagnostic pragma hides VLA warnings (frame check sees only functions emitted at -O0).
- every instrumented build (sanitizer test, ownership trace project+driver, lean vectors) uses build.instrumented_compile_flags: BUILD_FIDELITY_FLAGS after compile.flags.
- compile.flags MUST NOT carry -fsanitize*/-fno-sanitize* or tool-control options (specs/compile_options.TOOL_CONTROL_PREFIXES; spec validator); cbmc checks = spec.effective_cbmc_checks() (contract.safety included).
- compile.flags entry = one option, value joined; non-options/-/-- rejected by spec validator; integrity probes `clang -### <entry>` per entry, missing-value diagnostic or unclean probe -> ERROR. cbmc translator, stack checks, codegen_flags rely on this: read entries standalone, no separate-value parsing.
- stack frame check -include's a diagnostic-pragma-immune anchor before compile.flags so every codegen run writes .su (-fembed-bitcode=off after compile.flags); no .su -> ERROR. .su qualifier != static -> UNBOUNDED_STACK. frame check accepts only exit 0 (signal death -> ERROR).
- VLA/alloca check runs three views (backends/stack_check.UNBOUNDED_STACK_SCOPES): compile.flags as given (fail-closed: exit != 0 accepted only when every error line, located or not, is a parsed vla/alloca diagnostic); system-include options rewritten to -I after include_args, --system-header-prefix= dropped (rules/stack_checks.system_includes_as_user_includes); no compile.flags (main's check, fail-closed like view 1). only view 2 just adds violations (its compile failures ignored). the VLA check outcome MUST never be better than the no-compile.flags check (violations and errors). MUST NOT use -Wsystem-headers or tolerate diagnostics by printed file name (#line, -ivfsoverlay control it).
- compile.flags validator (specs/compile_options.REJECTED_FLAG_FAMILIES) also rejects preprocessor-output options (integrity reads `-E` with compile.flags; no linemarker for the file -> ERROR), --driver-mode, -Wwrite-strings (-fconst-strings). -Wdeprecated/-Wno-deprecated are not diagnostic-only. tests/test_soundness_flag_semantics scans every clang -W spelling for cc1 effects.
- C source rule TRIGRAPH: any ??[=/'()!<>-] in editable C text (clang ISO modes replace trigraphs, CBMC/Frama-C gnu preprocessing does not); strict C89/C90 and C23 standards, -ansi and -fdigraphs/-fno-digraphs rejected by the validator (tokenisation differs from gcc gnu modes); -ivfsoverlay/-vfsoverlay rejected. __FILE__ and raw string prefixes (R") in editable code -> TOOL_DIVERGENCE.

## check
- `python -m scripts.constraints` MUST exit 0 (run from repo root; rules from constraints.toml; `--fix` removes comments/docstrings only when the AST is unchanged and no encoding cookie, rewrites the layer block; `--json`).
- after a change: `python scripts/affected_tests.py --run` (import-graph selection vs HEAD; `--base <rev>` for a branch). MUST pass.
- before creating or merging a PR: commit everything, then `python -m scripts.merge_gate` MUST exit 0. it tests a fresh worktree of the pinned HEAD with PYTEST_*/PYTHON* env stripped. order: fetch base (explicit refspec) -> committed + base != HEAD + base ancestor -> worktree + leanc resolves into it -> constraints -> full suite (junit: tests>0, 0 failed/errors/skipped) -> experiments N/N (N>0) -> approvals made by base code valid under HEAD code -> worktree unchanged. stops at first failure; no skip.
- merge only after `MERGE GATE PASS head=<h> base=<b>`: fetch, confirm origin/main == <b> (else rerun the gate), then merge_pull_request expectedHeadSha=<h>, merge_method=merge. new commit after the gate -> rerun.
- gate needs clang-18 gcc cbmc bwrap, x86-64 CPU with AVX2; wp: frama-c>=27 with -print-machdep-builtin-macros at /opt/opam/*/bin; lean: /opt/lean/*/bin. ~20 min.
